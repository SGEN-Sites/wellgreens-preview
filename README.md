# Wellgreens: redesign preview

A redesign preview of [wellgreens.store](https://www.wellgreens.store/) (Wellgreens Dispensary, 10 stores across San Diego County), rebuilt on RISE Cannabis's site architecture. It keeps Wellgreens' brand, copy, products, photos and URLs.

**Preview:** https://sgen-sites.github.io/wellgreens-preview/

- This is **not** the live site. Every page is `noindex, nofollow`.
- English and Spanish, like the live site.
- Product data is a snapshot of the 10 stores' live menus, captured 2026-11-24/25 (15,643 products).
- Every **Order** button opens that product on the live wellgreens.store menu, where the cart and checkout are.
- The contact form is a preview: nothing is sent.
- Static HTML, CSS and JS with no framework, served by GitHub Pages from `main` (root).
